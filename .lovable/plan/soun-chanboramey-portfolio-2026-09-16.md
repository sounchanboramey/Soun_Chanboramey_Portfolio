# Soun Chanboramey Portfolio

## Overview
Build a polished single-page portfolio that presents Soun Chanboramey as a creative developer blending engineering, digital design, and entrepreneurship. The experience will use a dark-green and off-white editorial palette, bold typography, generous spacing, rounded project cards, and restrained motion.

## What will be built
- Sticky desktop navigation and accessible mobile menu with links to every section
- Hero with the provided biography, calls to action, and a custom developer-inspired visual composition
- About section with the provided profile summary and four key facts
- Categorized skills covering development, design, and professional strengths
- Filterable five-project gallery with editable placeholder artwork and links
- Vertical experience timeline using only verified role and date information
- Programs and achievements cards with icons and dates only where supplied
- Contact section with email, phone, location, social placeholders, and validated form fields
- Responsive layouts for desktop, tablet, and mobile with keyboard-visible focus states

## Technical details
- React and TypeScript components within the existing TanStack application
- Tailwind CSS v4 with semantic design tokens in the shared stylesheet
- Lucide React icons and reusable section, button, project, skill, and navigation patterns
- Client-side interactions for menu, filters, section scrolling, form validation, and subtle intersection-based reveals
- Route-specific title, description, Open Graph, and Twitter metadata
- No backend submission or invented social URLs; the contact form will validate and prepare an email draft
